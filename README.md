# SRPS Teaching Materials

Offline HTML teaching materials for Classes 6–10 Science (Physics & Chemistry).
Designed for Karnataka KTBS / NCERT syllabus, display on classroom TV at 1920×1080.

## Files

| File | Description |
|------|-------------|
| `Class10_Chemistry_MetalsNonMetals_interactive.html` | Click-to-reveal interactive lesson — 12 scenes |
| `Class10_Chemistry_MetalsNonMetals_slides.html` | 24-slide deck covering all definitions, reactions, diagrams |
| `Class10_Chemistry_MetalsNonMetals_simulations.html` | Canvas-based virtual lab — 5 animated chemistry experiments |

## Simulations (virtual lab)

1. **Metal + HCl Lab** — drop 8 different metals into acid, watch bubbles & reactivity
2. **Displacement Reaction** — Fe nail in CuSO₄, solution turns green over time
3. **Ionic Bond NaCl** — electron flies from Na to Cl, ions attract and form NaCl
4. **Mg Burning in Air** — Bunsen burner, white flame + sparks + smoke particles
5. **Rusting Experiment** — 3 test tubes, time slider, rust forms only where O₂ + moisture meet

## Usage

Open any `.html` file in Chrome — works fully **offline**, no internet needed.
Press **F11** for fullscreen on classroom TV (1920×1080).
Arrow keys navigate slides/scenes.
