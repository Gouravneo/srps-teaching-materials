Light Path
Object → Cornea (main refraction) → Aqueous Humour → Iris/Pupil (aperture) → Lens (fine focus) → Vitreous Humour → Retina (image formed, inverted) → Optic Nerve → Brain
Key Facts
Near point = 25 cm
Far point = ∞ (normal)
f varies: ~2.3 – 2.0 cm
The image on the retina is real and inverted. The brain corrects this so we perceive the world upright.

Accommodation range:
25 cm (near) → ∞ (far)
Near object: Ciliary muscles contract → lens thickens → shorter focal length → more converging power.

Far object: Ciliary muscles relax → lens flattens → longer focal length → less converging power.
