Formula Reference Sheet
🪞 Mirrors
1/v + 1/u = 1/f
f = R/2
m = −v/u = h'/h
u: object distance (always −ve)
v: image distance (−ve = real, +ve = virtual)
f: focal length (concave −ve, convex +ve)
m < 0: inverted  |  m > 0: erect
|m| > 1: enlarged  |  |m| < 1: diminished
🔍 Lenses
1/v − 1/u = 1/f
m = v/u = h'/h
P = 1/f(m)  [in metres]
u: object distance (always −ve)
v: +ve = real (right), −ve = virtual (left)
f: convex +ve, concave −ve
Power in Dioptres (D)
P_total = P₁ + P₂ + P₃
💧 Refraction & Snell's Law
n₁ sin θ₁ = n₂ sin θ₂
n = c / v
sin C = n₂ / n₁
n: refractive index (dimensionless)
c = 3 × 10⁸ m/s (speed in vacuum)
v: speed in medium
C: critical angle for TIR
TIR: denser → rarer, angle > C
📋 Sign Convention Summary
All distances from optical centre / pole
Along incident ray direction = positive (+)
Against incident ray direction = negative (−)
Heights above principal axis = positive (+)
Heights below principal axis = negative (−)

u always −ve (object in front)
Concave mirror f: −ve
Convex mirror f: +ve
Convex lens f: +ve
Concave lens f: −ve
